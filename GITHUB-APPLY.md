# Importera senaste källkoden till GitHub

Se START-HERE.md. Använd en klon av `adamchaadaev/YooKDS-by-Kassa-Express`, en ny
utvecklingsgren och en egen commit för denna alpha.2-källkodsimport. Behåll root
LICENSE, historiken och andra användarändringar. Det är inte en instruktion att
extrahera den gamla ZIP-filen som fortfarande ligger på main över den nya koden.

Kopiera projektets källkod och utvecklardokumentation, inte kunduppgifter eller
WordPress-installationen. Kontrollera `git diff` och staging innan push. En push
kräver användarens normala GitHub-behörighet; upprepa inte nekade integrationsanrop.
