YooKDS är ett köksskärmsystem (Kitchen Display System) byggt för WooCommerce.
Det gör det möjligt att hantera beställningar i realtid, dela upp dem mellan olika stationer och visa status på ett tydligt och modernt gränssnitt.

Funktioner
	•	Hantering av flera stationer (t.ex. grill, sallad, dryck)
	•	Realtidsuppdateringar och asynkron filtrering
	•	Automatisk synk mellan WooCommerce och KDS
	•	Möjlighet att koppla stationer till specifika produktkategorier
	•	Dashboard med statistik och orderstatus
